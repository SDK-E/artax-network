# Roadmap

## v0.1 — Foundation

- Event-driven runtime core
- Event bus and event loop
- Working memory subsystem
- Scheduler subsystem
- Chromium driver (alpha)
- Developer dashboard (alpha)

## v0.2 — Terminal Access

- Terminal driver for shell interaction
- Improved memory persistence
- SQLite and Redis memory backends

## v0.3 — Code Intelligence

- VS Code driver for editor integration
- Plugin system for extending drivers and memory backends
- Tool-call abstraction layer

## v0.4 — Desktop Environment

- Desktop environment driver
- Window management and GUI interaction primitives
- Cross-platform input simulation

## v0.5 — Simulation

- Unity simulation environment driver
- Unreal Engine simulation environment driver
- Physics-based action validation

## v0.6 — Robotics

- ROS 2 integration driver
- Hardware abstraction layer
- Real-time constraint support

## v1.0 — Production Ready

- Stable API for all core drivers
- Production-hardened runtime
- Comprehensive documentation and examples
- Performance benchmarks
